Automatically uses a Light palette when your device is in light mode and a Ghostty palette when it is in dark mode. Select **Auto · Light / Ghostty** under Settings → Appearance → Theme once. Requires Paseo 0.12.0 or later on both the daemon and client. The palettes adapt Paseo's built-in themes to the plugin API, so some color details differ. Detection runs on your device; a native app appearance override can take precedence over the system preference.
