Automatically switches interface palettes with your device's light or dark mode. Choose **Auto · Light / Ghostty** or **Auto · GitHub Light Default / One Dark Pro** under Settings → Appearance → Theme. Requires Paseo 0.12.0 or later on both the daemon and client. Palettes are adapted to Paseo's limited plugin API, so some color details differ; syntax highlighting is configured separately in Paseo. Detection runs on your device; a native app appearance override can take precedence over the system preference.
